# Design Traceability Matrix

This matrix maps the main classes and interfaces in MediTrack to the design principle, pattern, or architectural role they represent, and points to the docs where that choice is explained.

This list covers the classes and interfaces with explicit design intent. Simple enums, constants, and small helper-only types are already covered in the domain sections and UML, but they are not listed separately because they do not represent separate design patterns on their own.
